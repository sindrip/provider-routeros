# Observations before code

Each layer is produced by the one before it: harness boots a disposable
router → probes pin observations → the IR compiles them → the generator
emits Kinds and descriptors → the engine reconciles them. No schema is
written by hand and nothing is derived from documentation; the manual has
been caught wrong in both directions. Probes speak REST — machine-shaped
JSON, where console output is presentation. Observations are re-pinned on
current stable, never copied forward: an observation the pipeline cannot
reproduce is a claim.
